Banking Data Analysis Project (Excel)
Overview

This project is part of my journey in learning Data Analysis.
It focuses on analyzing banking data using Microsoft Excel, with an emphasis on data cleaning, transformation, modeling, and visualization.

Through this project, I gained deeper insights into banking operations, loan analysis, and customer segmentation.

Objectives
Clean and transform raw banking data
Build a structured data model
Extract meaningful business insights
Create an interactive dashboard for decision-making
Tools & Technologies
Microsoft Excel
Power Query
DAX (Data Analysis Expressions)
M Language
Data Modeling (Star Schema)
Project Workflow
Data Cleaning & Transformation
Used Power Query to handle missing values and data inconsistencies
Performed data preprocessing and formatting
Ensured data quality for accurate analysis
Data Transformation with M Language
Created custom columns using M Language
Applied transformations to enhance dataset usability
Data Modeling
Designed a Star Schema model
Built relationships between fact and dimension tables
Optimized data structure for analysis
Data Analysis with DAX
Developed KPIs (Key Performance Indicators)
Created calculated columns and measures
Enabled deeper analytical insights
Dashboard Development
Built an interactive Excel dashboard
Visualized key banking metrics, including:
Loan Distribution
Customer Segments
Risky Loans
Loan Amount per Branch
Key Insights
Identified patterns in loan distribution across branches
Highlighted high-risk loans for better decision-making
Segmented customers based on financial behavior
